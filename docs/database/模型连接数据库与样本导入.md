# 模型连接数据库与样本导入

模型连接与用户、团队和知识库共用 MySQL 业务库 `direction_classifier`。`dev,mysql` 启动时，Liquibase 通过 `db.changelog-users.yaml` 加载 `model/4.0.0-schema.sql`。`direction_classifier_test` 用于独立验收。

| 表 | 用途 |
| --- | --- |
| `demo_model_connection` | 保存连接身份、所有者、可见范围、启停状态和当前修订。对象级授权可沿用 `demo_resource_grant`，资源类型为 `model_connection`。 |
| `demo_model_connection_revision` | 固定协议、模型用途、实际模型 ID、Base URL、认证方式、凭据范围以及适配和路由参数。每条连接可保存多个只读修订。 |
| `demo_model_credential` | 按连接及凭据范围保存生效或已撤销的凭据版本。更换 Key 在同一事务内撤销旧凭据并新增版本。 |
| `demo_model_connection_test` | 逐次记录实际测试的地址、修订、凭据版本、HTTP 状态、耗时、脱敏回复和错误。换 Key 或修订后，按新的组合查询测试结果。 |

`routing_options_json` 可用 `additional_endpoints` 数组描述附加地址，每项包含 `base_url` 和权重。测试地址必须属于该修订。普通模型调用可按修订的 `credential_scope_key` 解析当前凭据。同服务换 Key 保留该范围。更换地址范围后为新范围配置凭据，旧修订仍指向原范围。

## 工作台使用

在用户与团队页面登录后，进入工作台的「模型连接」。列表支持按名称、模型类型和启停状态查询。可查看配置修订及最近测试记录，按权限新增、编辑、复制、启停和测试。团队共享允许有效成员使用和测试连接，连接所有者可维护配置和凭据。方法配置下拉框读取当前有权使用的真实模型修订。

新增连接时填写 OpenAI 兼容 Base URL、模型 ID、模型用途和认证方式。对话测试发出固定短消息，向量测试发出固定短文本并显示返回维度。配置附加地址后，可选择某个地址单独测试。列表显示当前修订和凭据在主地址上的最近结果。API Key 留空时保留同一地址范围的凭据。副本有独立的配置与凭据。

公网服务使用 HTTPS。使用内网服务或本机代理的虚拟地址解析时，在启动应用前用 `CLASSIFIER_MODEL_PRIVATE_BASE_URLS` 配置逗号分隔的完整 Base URL。Windows 启动脚本也支持从私有目录下的 `.local/model-secrets/approved-base-urls.txt` 读取地址，每行一个，环境变量优先。生产部署可通过 `CLASSIFIER_MODEL_CREDENTIAL_KEY_FILE` 指定受保护的主密钥路径。

## 导入和复测

先启动项目专用 MySQL，重新打包并按 `dev,mysql` 启动一次应用以执行迁移。启动命令见 [Windows 本地启动](../../STARTUP-WINDOWS.md)。从项目根目录运行以下命令。所用 Python 环境需要安装 `openai`、`httpx`、`python-dotenv`、`pymysql` 和 `cryptography`。

```powershell
& .\scripts\init-model-credential-key.ps1
$algorithmDir = (Resolve-Path -LiteralPath '../../学科交叉算法接口/direction-classifier').Path
python -X utf8 .\scripts\import-model-samples.py `
    --database direction_classifier `
    --env-file (Join-Path $algorithmDir '.env') `
    --expected-base-url '<控制台给出的 OpenAI 兼容 Base URL>'
```

脚本校验 MySQL 实例标识及 `.env` 地址，读取 `QWEN_API_KEY`、`QWEN_BASE_URL` 和 `QWEN_MODEL`，向当前启用的本地初始管理员创建两个私有样本。`qwen-live` 使用真实凭据，`qwen-invalid-auth` 使用同一地址和模型以及无效测试凭据。相同配置和凭据重复导入时复用对应记录。每次复测都从数据库读回并解密当前凭据，发起固定短请求，然后追加测试结果。退出码为 `0` 表示真实样本调用成功且对照样本返回鉴权失败。

本地凭据使用 AES-256-GCM。密文按 12 字节随机 nonce、密文和认证标签的顺序写入，关联数据绑定数据库、连接、凭据范围和凭据版本。解密主密钥位于 Git 忽略的 `.local/model-secrets/local-aes-gcm-v1.bin`，由私有 ACL 保护，`LAPTOP-BDKBMPCD\JHY` 保留完全控制。恢复数据库时需同时恢复原主密钥，密钥备份应独立保管。

## 首次验收

2026-11-11，业务库和独立测试库均执行了 10 条模型连接变更集。业务库的两个 `qwen-plus` 样本分别记录了 HTTP 200 调用成功和 HTTP 401 鉴权失败。独立测试库验证了重复导入、修订只读、凭据范围隔离、轮换保留历史引用、测试地址校验和结果只追加，测试数据已回滚。

独立测试应用使用以下配置时，可复测页面背后的模型连接接口。测试会创建并停用一组独立的测试连接。

```powershell
$env:CLASSIFIER_MODEL_PRIVATE_BASE_URLS = 'http://127.0.0.1:18764/v1,http://127.0.0.1:18764/backup'
& .\scripts\start-users.ps1 -TestDatabase -Port 8083 -ManagementPort 9083
# 从另一个终端运行
python -X utf8 .\scripts\test-model-connections.py

```
