# 各页面展示数据与功能计划

日期：2026-11-11。适用项目：学科交叉算法调试系统。

本文将前期页面设计、后续范围调整和已完成的用户模块合并为页面级计划，说明每页展示哪些数据、支持哪些操作，以及与其他页面如何协作。本文是后续实现和验收的目标说明，不表示所有规划功能都已实现。

相关文档：[后续业务数据库设计与实施计划](../database/后续业务数据库设计与实施计划.md)、[用户模块已完成功能](user-module-completion.md)、[用户模块测试报告](user-module-test-report.md)。

## 1. 统一范围与页面结构

### 1.1 本期范围

- 应用客户与算法开发者使用同一套页面，基础配置默认展示，高级配置按需展开。
- 识别主流程为：输入解析 → 簇路由 → 学科召回 → 独立精判 → 后处理 → 学科结果。
- 交叉度仅接收、存储、展示和导出外部提供的结果，不实现计算公式，不要求 N、D、K。
- 不实现论文研究要素抽取、句子定位、要素学科识别和人工改句；数据与流程结构保留扩展能力。
- 学科画像中的核心任务、边缘任务、交叉任务和区分规则属于知识库，仍需管理和展示。
- 已保存的方法、知识库版本及历史结果只读；永久修改在对应对象的草稿中完成。

### 1.2 页面清单

| 入口 | 主要页面 | 附属界面 |
| --- | --- | --- |
| 识别方法 | 方法列表、方法详情 | 新建／复制／重命名弹窗；流程配置与版本记录页签；保存新版本弹窗 |
| 学科知识库 | 知识库列表、知识库详情 | 资源页签、导入界面、离线生成抽屉、引用查看抽屉、保存版本弹窗 |
| 单篇调试 | 调试工作页 | 阶段详情、调用详情、临时干预弹窗、调试历史抽屉 |
| 批量识别 | 任务列表、新建任务、任务详情 | 三步创建向导、单条历史结果抽屉、导出状态 |
| 设置／模型连接 | 模型连接列表 | 新建／编辑／只读抽屉、连接测试结果 |
| 总览／工作台 | 现有总览页，作为快捷入口 | 最近任务、最近调试、快捷操作；不增加独立业务对象 |
| 用户与团队 | 登录、个人资料、用户管理、角色管理、功能权限、导航菜单、团队管理 | 修改密码、编辑表单、授权选择、团队成员面板及负责人转交 |

前五个业务入口仍为九个主要页面。总览是现有快捷工作台；账户与管理页面作为独立管理入口或用户菜单进入，不将账号资料和模型连接混成一页。

| --- | --- | --- |

| 研究要素与交叉度计算 | 旧原型保留相关示意 | 本期真实流程不显示为已实现或已执行，不据此扩大开发范围 |

## 2. 所有页面共同遵守的交互规则

| 场景 | 页面处理 |
| --- | --- |
| 查找对象 | 列表提供搜索、范围筛选和分页，详情承担编辑 |
| 没有权限 | 后端校验；前端隐藏或禁用不可执行操作，不能只依赖按钮控制 |
| 草稿与版本 | 显示清楚的状态和版本号；已保存版本只读，可基于它创建草稿 |
| 默认版本与最新版本 | 分开显示；建议快捷运行优先带入默认使用版本，未设置时采用最新保存版本，并始终展示实际带入的版本 |
| 基础与高级配置 | 高级配置只是展示偏好，不决定用户是否拥有操作权限 |
| 普通字段为空 | 显示“未填写”或空占位；允许显式清空，关键操作按实际条件校验 |
| 未保存离开 | 提供保存草稿、放弃修改、取消离开；不能静默丢弃 |
| 耗时操作 | 显示真实任务或运行状态、进度、错误及可恢复入口，不用模拟进度冒充后端执行 |
| 保存失败 | 保留用户输入并显示原因；不能提示成功或回退为 mock 成功 |
| 查看历史 | 读取固定快照，不触发重算；重新运行显式创建新过程 |
| 对象改名、归档或停用 | 不改写历史依据；历史展示保留原快照，新的使用受当前权限和状态约束 |
| 文件下载 | 按业务权限获取文件；不展示服务器磁盘路径或包含凭据的链接 |
| 状态反馈 | 区分未开始、处理中、完成、失败、未提供、已失效，不能用0或空表掩盖错误 |

基础页面不展示数据库表名、原始请求 JSON 或内部文件路径。开发者需要的调用细节放在折叠区或详情抽屉。

## 3. 总览／工作台

**目的：** 帮助用户找到最近工作并进入正确页面，不承担配置编辑和效果评估。

### 展示数据

- 当前用户名称、可进入的业务入口。
- 可使用的方法数量、可访问知识库数量，以及本人或有权查看的任务状态摘要。
- 最近使用的方法：名称、默认使用版本、关联知识库版本、最后使用时间。
- 最近批量任务：名称、状态、成功／失败／待处理数及更新时间。
- 最近已保存调试：输入标题、方法版本、主学科、保存时间；交叉度仅在有值时展示。
- 与本人有关的可处理事项，如草稿未保存、任务失败、本人管理的连接测试失败。

### 支持功能

- 新建方法、新建批量任务、进入单篇调试、进入用户与团队管理。
- 点击最近对象进入其具体详情和版本。
- 按当前权限隐藏不可访问的对象和操作。

### 不承担的内容

- 不展示尚未建设的准确率、方法效果对比、研究要素统计或交叉度计算分析。
- 不将全库总量作为个人可访问数量；待更新事项应可点击处理，不能仅放装饰性提醒。

## 4. 识别方法列表

**目的：** 找到方法、创建方法、选择配置或执行。主要动作为“新建方法”。

### 展示数据

| 区域 | 数据 |
| --- | --- |
| 页头 | 名称、简短说明、新建按钮 |
| 查询区 | 名称搜索、我的／团队共享／内置模板、学科体系、分页 |
| 每个方法 | 名称、说明、所有者、所属体系、最新保存版本、默认使用版本、关联知识库、更新时间、草稿状态 |
| 可用性提示 | 未保存版本、配置缺失、依赖停用或仅可查看等必要状态 |

### 支持功能

- 查看／配置：进入方法详情，定位当前草稿或所选保存版本。
- 单篇调试、批量识别：带入明确的已保存版本；无可用版本时提示先完成保存。
- 创建副本：复制指定版本的配置和知识库引用，生成本人草稿并记录来源。
- 重命名、修改说明、归档；根据所有权和授权提供操作。
- 列表中的共享／内置方法可使用或复制，但不能直接修改他人已保存版本。

这里不铺开提示词、阶段参数、模型分配或完整版本列表。

## 5. 方法详情：流程配置与版本记录

**目的：** 解释并配置算法如何工作。主要动作为“保存新版本”，草稿保存作为持续编辑操作。

### 5.1 顶部身份与依赖

展示方法名称、说明、所有者、体系、草稿／保存版本状态、来源版本、关联知识库及其具体版本、草稿是否有未保存编辑。

支持保存草稿、保存新版本、切换查看版本、基于版本创建草稿、前往单篇调试、前往批量识别。

不设置笼统的“当前模型”；模型在对应阶段配置。

### 5.2 流程图

本期流程图显示：输入解析、簇路由、学科召回、独立精判、后处理、学科结果。

- 节点只显示名称和简短状态。
- 区分当前选中、可配置、有未保存修改、配置不完整和只读状态。
- 知识库与索引等作为依赖显示，不将其编辑器嵌进方法配置。
- 交叉度是可选结果指标，不展示成已经实现的计算节点。
- 研究要素相关分支不启用，也不提供可执行的占位按钮。

### 5.3 选中节点的配置面板

| 节点 | 基础配置 | 高级配置 |
| --- | --- | --- |
| 输入解析 | 使用字段、文本组织方式、摘要长度 | 缺失字段处理、清洗与截断规则、内容类型是否参与判断 |
| 簇路由 | 模型连接配置、选簇上限 | 提示词、选簇下限、补充策略、调用参数 |
| 学科召回 | 已实现的召回策略、动态／固定数量、候选上限 | 候选下限、补足规则、提示词、相应模型与参数 |
| 独立精判 | 模型连接配置、规则模板 | 完整提示词、变量说明、温度、输出长度、超时／重试策略 |
| 后处理 | 高度相关上限、最低保留等级、输出数量 | 排序、降级、过滤和失败处理规则 |
| 结果 | 输出说明及实际支持的字段 | 可选输出结构设置，不配置交叉度公式 |

模型分配以阶段用途为准。LLM召回也必须有可用模型；选择向量策略时才展示编码模型、索引和向量参数。尚未实现的策略标明待实现，不允许发布为可执行配置。

### 5.4 校验与保存

- 检查模型绑定、知识版本、资源范围、提示词变量、上下限和已实现策略。
- 向量策略检查模型与索引兼容；LLM策略不因缺少向量索引而被阻止。
- 本期不因缺少相似度表或要素配置而阻止保存可执行方法。
- 配置问题定位到对应节点和字段。
- 保存新版本要求填写一句修改说明，保存后只读。
- 更新知识版本或模型配置修订需要显式选择；Key更换不形成方法新版本。

### 5.5 版本记录页签

展示版本号、保存时间、保存人、说明、知识版本、修改概要、是否默认版本。

支持查看配置、按该版本单篇／批量执行、基于旧版本创建草稿、设置默认使用版本。第一期不开发复杂差异可视化或效果对比。

## 6. 学科知识库列表

**目的：** 找到、创建或导入知识库。主要动作为“创建知识库”。

### 展示数据

- 名称、说明、学科体系、实际学科数量、所有者、共享范围。
- 最新保存版本、默认版本、更新时间、草稿状态、待更新资源提示。
- 名称搜索、体系和可见范围筛选、分页。

### 支持功能

- 创建知识库、导入知识库、查看／编辑。
- 基于指定保存版本创建副本。
- 按权限修改名称、说明、共享范围或归档。

数量从实际资源计算，不能使用原型中的116等示意数量，也不能根据缓存文件名猜测范围。

## 7. 知识库详情：资源与版本

**目的：** 管理离线知识资源。主要动作为“保存新版本”。

### 7.1 顶部与公共操作

展示名称、所有者、体系、当前草稿／版本、资源数量摘要、待更新／校验状态。

支持保存草稿、保存新版本、资源检查、查看被哪些方法版本引用。引用抽屉只显示当前有权查看的对象，不泄露他人私有方法名称。

已保存版本全部只读；编辑、导入、生成写入均作用于草稿。

### 7.2 资源页签

| 页签 | 展示数据 | 支持功能 | 重要规则 |
| --- | --- | --- | --- |
| 学科画像 | 左侧目录；右侧代码、名称、原始定义、核心／边缘／交叉任务、区分规则、算法使用文本 | 搜索、编辑、添加学科、导入导出；高级区查看结构化内容 | 保存完整任务结构，不能只保留几段展示文本 |
| 召回摘要 | 学科、短摘要、关键词、来源画像、是否待更新 | 编辑、生成、重新生成、预览 | 画像修改后提示更新，不自动覆盖摘要 |
| 学科簇 | 编号、名称、描述、关键词、成员及覆盖情况 | 修改、调整成员、检查成员有效性和覆盖 | 不假定每个学科只能属于一个簇；不自动移动成员 |
| 种子论文 | 所属学科、标题、摘要、作者、出版信息、DOI／原始文献标识、来源、是否参与生成 | 导入、添加、编辑、移除、选择参与生成 | 不强制将CNKI等来源标识当作标准DOI；保留原始编号 |
| 相似度资源〔可选〕 | 文件名称、来源、适用范围、版本和说明 | 上传、下载、替换草稿附件 | 本期不承诺逐学科对编辑、检索、覆盖率和交叉度计算 |
| 索引资源〔策略需要时〕 | 索引类型、来源版本、编码模型、维度、条目数、构建状态 | 查看、构建／重新构建、检查兼容性 | 仅在对应向量策略真实实现后提供可用操作 |
| 版本记录 | 版本、说明、保存人、时间、资源摘要 | 查看、导出、基于旧版创建草稿 | 不覆盖已引用的历史资源 |

### 7.3 知识库导入界面

展示原文件、识别出的资源类型、学科体系、学科数量、字段对应、缺失或冲突清单、导入预览。

用户确认后写入目标草稿。跨体系代码、重复代码、未知成员或无法解析的数据明确报告；原始文件和来源信息保留。导入失败不显示为完成，也不修改已保存版本。

### 7.4 离线生成抽屉

展示本次目标资源、所用输入及其来源、生成规则／模板、模型连接配置、参数、进度、失败项和结果预览。

支持启动、查看结果、重试失败项、确认写入草稿。源画像或草稿在生成期间发生变化时提示冲突，保留预览，不自动覆盖新编辑。

生成配置与在线识别方法配置分开。生成成功不等于已写入草稿，写入草稿也不等于已保存新版本。

## 8. 单篇调试工作页

**目的：** 用一篇内容运行、观察并定位方法问题。主要动作为“运行识别”。

### 8.1 顶部运行依据

- 方法名称、已保存版本选择。
- 一行知识库版本说明。
- 查看方法配置、运行识别、调试历史入口。

不重复铺开所有模型、参数和资源。历史模式明确显示“正在查看历史快照”，并把重新运行作为独立操作。

### 8.2 输入区

| 展示层级 | 数据 |
| --- | --- |
| 默认 | 内容类型、标题或名称、关键词、摘要或内容说明 |
| 更多信息 | 期刊／会议、DOI、年份或原出版信息、外部编号 |
| 辅助操作 | 填入示例、清空、从历史载入 |

输入校验以所选方法的字段规则为准。仅有编号等元数据不能代替必要文本；内容类型是否进入模型输入也由方法决定。导入数据中的真实学科标签不默认拼入识别提示词。

### 8.3 运行过程

先显示阶段名称及未开始、运行中、已完成、失败、复用前置结果、人工调整／待重算等状态。进度来自后端，进入页面不触发自动运行。

| 阶段 | 点击后展示的数据 |
| --- | --- |
| 输入解析 | 实际解析字段、缺失处理、清洗／截断情况、实际组织文本 |
| 簇路由 | 选中簇、次序、路由等级／理由、成员学科 |
| 学科召回 | 候选学科、召回来源与名次、等级、分数及其类型、补足标记 |
| 独立精判 | 每个候选的等级、理由、匹配任务／特征、边界解释、置信信息、失败状态 |
| 后处理 | 原始与最终等级、排序变化、降级和过滤原因 |
| 结果 | 主学科、相关学科、简要说明及可选交叉度状态 |

调用详情默认折叠，展示实际请求／提示词、原始响应、解析结果、耗时、重试和错误。认证头、Key等不展示；未采集字段显示“未采集”，不能补充模拟内容。

### 8.4 临时调试操作

- 手动加入当前知识版本内的候选学科并执行精判。
- 重试失败阶段。
- 从选中阶段重新运行后续过程。
- 恢复查看原算法结果。

干预建立新运行分支并保留调整前结果，受影响结果标为待重算。恢复算法结果是切回保留快照，不是覆盖或删除人工调整历史。

永久提示词、规则、参数和模型分配仍跳转方法详情修改。第一期没有“修改要素句子”操作。

### 8.5 结果区与交叉度

默认展示主学科、其他相关学科与等级、简要说明；有外部交叉度时展示指标值及状态。

展开可查看完整学科排名、证据、后处理说明、指标来源／版本／生成时间，以及外部确实提供的可选详情。

- 未提供交叉度时显示“未提供”，不显示0，也不影响识别成功状态。
- 调整学科结果后，旧指标不作为新结果的有效值，显示等待重新提供。
- 不显示N／D／K计算面板、计算按钮或研究要素分支。
- 后续补充指标形成新的结果修订，原保存历史不自动改变。

### 8.6 调试历史抽屉

展示标题、方法版本、知识版本、主学科、可选交叉度及状态、执行状态、时间、执行人和人工干预标记。支持按标题、方法、时间等查询。

支持保存终态运行、查看快照、载入输入重新调试、导出。进行中运行可继续跟踪，不提前保存成最终结果。重新运行产生新记录，原记录不覆盖。

## 9. 批量任务列表

**目的：** 找到任务并查看执行或获取结果。主要动作为“新建批量任务”。

### 展示数据

- 任务名称、方法及版本、提交时间。
- 提交执行数、成功数、失败数、待处理数、状态和真实进度。
- 名称搜索、状态筛选、分页。

### 支持功能

- 查看任务详情。
- 导出已有成功结果。
- 重试失败项；无失败项时禁用。
- 复制任务进入新建向导；使用新方法版本必须创建新任务。

不加入准确率、方法对比或实验分析。团队任务是否可见以明确的任务授权为准，不因同属团队自动展示所有输入内容。

## 10. 新建批量任务

**目的：** 确认方法和数据后提交。采用三步向导。

### 第一步：选择方法

展示和填写任务名称、可使用的方法及已保存版本；只读展示该版本引用的知识版本和简短方法说明。

支持从方法页带入版本、选择其他保存版本、查看配置。草稿不作为正常批量执行依据。

### 第二步：上传与检查

展示模板下载、文件、工作表、字段映射、业务编号规则、数据预览、有效／异常数量和逐行问题。

- 目标支持CSV和XLSX；现有原型只有CSV，XLSX解析与工作表选择属于待实现内容。
- CSV编码不兼容时明确提示或提供编码选择，不能用乱码继续识别。
- 映射标题、关键词、摘要、期刊、出版信息、DOI、外部编号等实际需要字段。
- 检查必要文本、重复业务编号、无法映射字段和无法解析行。
- 现有数据id跨学科复用时，可选择“学科代码+id”等业务键，保留原始编号，不静默覆盖记录。
- 异常行保留原行号、原始内容和原因，支持下载清单。
- 允许修正后重新上传；或者明确勾选跳过异常行，并展示将跳过的数量。

### 第三步：确认提交

集中展示文件名称、选定工作表、有效数、异常数、跳过数、实际提交数，以及方法／知识版本摘要。

支持返回修改、提交任务。提交成功后进入任务详情；重复点击不能建立重复任务。提交后文件、映射和运行版本固定。

## 11. 批量任务详情

**目的：** 跟踪任务、定位失败、查看历史结果并导出。

### 顶部摘要与状态

展示任务名称、方法／知识版本、输入文件、提交人与时间、开始及完成时间；区分原始上传数、有效提交数、跳过数、成功、失败和待处理数。

运行中可以离开页面后重新查看；恢复或重试不改变原方法版本。错误分为文件校验异常、条目执行失败和指标未提供，不能混为识别失败。

### 默认结果表

| 字段 | 展示约定 |
| --- | --- |
| 外部编号 | 展示来源编号或已确认的业务键，内部行身份仍唯一 |
| 标题／名称 | 长文本截断，详情查看完整内容 |
| 主学科 | 无有效结果时显示对应状态，不填模拟学科 |
| 其他相关学科 | 简要标签或数量，完整等级和理由进入行详情 |
| 交叉度 | 可空，配合未提供／有效／待更新等状态 |
| 条目状态 | 待处理、运行中、成功、失败等 |

支持按状态和学科筛选、分页、查看单条完整结果、导出成功结果、导出执行失败清单、下载导入异常清单、重试失败项。

### 单条历史结果抽屉

展示原始输入、固定方法／知识版本、完整学科结果、实际可用的阶段与调用信息、交叉度及来源、失败与重试记录。

“查看原任务结果”只读取历史快照；“复制输入到单篇调试”创建新的调试过程，并保留来源关系。

导出明确范围与结果修订。没有交叉度的单元格保持缺失，并附带状态字段；导出失败应显示原因，不返回空文件冒充成功。

## 12. 设置／模型连接

**目的：** 管理可使用的模型服务与凭据。主要动作为“新增连接”。

### 12.1 连接列表

展示连接名称、服务地址、模型名称、对话／向量类型、所有者／可使用范围、当前配置修订、启停状态、最近测试结果及时间。

支持搜索、类型／状态筛选、新增、查看／编辑、复制、测试和启停。复制以公开配置为主，不将凭据带入普通导出或页面快照。

### 12.2 新建／编辑抽屉

| 基础字段 | 展示及操作 |
| --- | --- |
| 连接名称与说明 | 让用户识别服务用途 |
| 协议、Base URL、模型名称 | 具体调用配置；需要时提供高级备选地址等配置 |
| 类型 | 对话模型或向量模型，供阶段按用途选择 |
| API Key | 只显示是否已配置或掩码，支持更换；不回显原Key |
| 可使用范围 | 个人／团队等授权范围，受所有者和授权能力约束 |

Key留空且未提出更换时保留旧凭据，掩码字符串不能被当作新Key提交。是否需要Key按协议和服务要求判断。

编辑模型名称、协议或地址形成新配置修订。明确告知：已保存方法仍使用原修订，需在方法草稿中切换；单纯更换Key不要求方法新版本。

这里不配置阶段分配、算法温度、召回数量或识别提示词。

### 12.3 测试结果

展示连通状态、模型是否可调用、耗时、简短脱敏示例、错误原因及测试时间。

测试采用固定请求，不表示识别准确率。已停用连接不用于新的执行；历史方法和调用仍可显示其名称和配置依据。

## 15. 页面验收清单

- 列表能找到对象，详情能解释并编辑草稿，运行和历史能看清依据。
- 所有页面区分已保存、草稿、未保存编辑；旧版本不能直接改写。
- 快捷跳转带入正确版本，默认版本与最新版本不混淆。
- 普通字段可清空，表单错误能定位；NULL不会显示为虚假的0或成功。
- 当前用户看不到或无法操作无权访问的资源；后端也能拦截越权ID。
- 模拟操作没有混入已接入页面，未实现策略或生成能力没有伪装成可执行按钮。
- 过程数据来自真实运行，失败、部分结果、重试与人工干预可区分。
- 交叉度可以缺失；本期没有要素抽取、改句或N／D／K计算的功能承诺。
- 批量异常行不丢失，原结果查看与重新调试明确分开。
- 原始请求、模型Key、数据库凭据、磁盘路径等内容按其用途与权限处理，不默认铺在基础页面。
- 用户离开、刷新、重试或服务重启后，已保存对象和历史仍可正确找到。
- 新增下载、导出和本地配置文件继续保证JHY的完全控制权限。

建议按“模型连接与共同基础 → 知识库 → 方法 → 单篇 → 批量 → 离线生成／按需策略 → 总览与联合验收”逐步接入。每个页面完成后同步给出实际已完成范围，不以页面有按钮作为功能已完成的依据。
